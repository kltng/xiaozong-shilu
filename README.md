# 明孝宗實錄: from scan to database

A draft website: the Veritable Records of the Hongzhi reign (1487–1505) as a table of dated
records, with persons and places linked to CBDB and TGAZ, every page as read by OCR, and
every step of the work (00 to 09) with its notes, numbers, code and sample output.

Site: https://kltng.github.io/xiaozong-shilu/

The text is machine-read and not proofread. The person and place links were made by rules
and have not been reviewed. This repository holds only the built site; it is generated by
a script and should not be edited by hand.
